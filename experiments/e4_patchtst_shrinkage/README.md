# E4 后续：固定残差收缩＋三种子复验

seed42 的开发集诊断发现：原 PatchTST MAE=0.217153903、MSE=0.135046476；残差乘 0.5 后 MAE 约 0.215092894，乘 0.25 后 MAE 约 0.215685626、MSE 约 0.130147701。这个方向基于已经观察过的开发结果，不是独立盲测发现。

本轮只验证这个改动，保留原 E4 和原有内部测试记录。新增目录独立于旧实验。

## 固定协议

- 复用 seed42 的原权重与预测；仅补跑 seed43、44。PatchTST 与同条件 DLinear 都按原配置复验。
- 原模型、输入、损失、优化器、样本顺序生成方法、batch512、4 线程、12 轮上限、patience4、min_delta1e-5 全部保持原 E4 设置。
- 通过独立模块命名空间复用旧训练函数，仅改变输出目录；原训练源文件和原模块的全局路径均不修改。
- 各种子仍按**未收缩的开发 MAE**选择原始最佳训练轮，校准统一基于 `best_trained.pt`。原始训练的 epoch0 早停规则保持不变；alpha=0 另作 E0 回退参照。
- 只比较两个固定系数：**0.5（主候选）、0.25（对照）**。三个种子必须用同一个 alpha，预测等权平均。
- 系数 1 为未收缩参照，0 为 E0。DLinear 也做相同系数对照，避免把一般校准收益全部归因于 Transformer 架构。

## 开发集通过门槛

较强参照固定为以下三者中开发 MAE 最低者：原增强 E1、校准后的匹配 DLinear 三种子平均、未收缩 PatchTST 三种子平均。

候选必须同时满足：

1. 平均预测的开发 MAE 改善至少 0.1%。
2. 开发 MSE 不比该参照恶化超过 0.5%。
3. 至少 2/3 个种子优于各自未收缩版本。
4. 较早／较晚两个开发时段的 MAE 分别不恶化超过 0.5%。

两个系数都通过时选开发 MAE 更低者；差距不超过 1e-5 时选主候选 0.5。前后开发时段仍来自相同开发数据、滑窗也相关，不是新的独立测试。

只有通过全部门槛，才导出所选全局系数的三个冻结权重，固定哈希后统一测试。不会在测试集比较两个系数再挑较好者。未通过则保留开发结果并停止，不追加配置或重评测试。

## 空间与复现

使用原 CPU 环境；数据只在内存中处理，不安装 GPU 环境、不复制原始数据、不写大缓存。只保存新增种子权重、小型预测数组、曲线和协议。

仓库根目录运行：

```powershell
./.venv/Scripts/python.exe -m unittest experiments.e4_patchtst_shrinkage.test_calibration
./.venv/Scripts/python.exe -u -m experiments.e4_patchtst_shrinkage.run --package-dir ../../hs300_train_val
```

已有运行加 `--resume`，会验证代码、协议和源权重，保留已完成结果并恢复未完成种子的最近完整 epoch。结果在 `RESULTS.md`、`results/`；新增种子原训练记录在 `replicas/seed43/results/`、`replicas/seed44/results/`。所有 `outputs/` 与权重由 gitignore 排除。

导出的 `outputs/frozen/` 权重已包含收缩系数，推理不要再次乘 alpha。PatchTST 是非线性模型，三个种子使用三个模型的预测平均，不把权重简单平均成单模型。

内部 holdout 此前已被观察，不能把本轮称为新的盲测、官方隐藏测试或已证明跨时期稳定的结果。源码和协议会记录这种限制。
