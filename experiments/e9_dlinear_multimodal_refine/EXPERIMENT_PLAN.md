# E9 后续实验：证明互补性，再决定是否保留双模态

## 当前事实与目标

旧 E9 开发 MAE 为 0.217979966，优于 E6 的 0.218732825，但弱于旧 E7 的 0.217031903。财报内容和新闻语义置零都几乎不影响指标。审计发现两个编码器的范数明显缩小，门控因统一 L2 从约 0.12 向 0.5 移动。

目标不是强行保留三种模态，而是证明：**修复后的联合模型稳定优于同条件下更好的单模态模型，且新闻与财报内容确实参与改善**。

## 固定条件与阶段顺序

行情沿用匹配种子的冻结 E6；数据切分、行情表示、新闻日期桶／去重规则、财报 180 天可用性与掩码规则固定。本轮不再看内部测试集，后续也不允许为了较低测试数字挑诊断分支。

| 编号 | 要验证的假设 | 唯一主要改变 | 必要对照 | 下一步／停止条件 |
|---|---|---|---|---|
| M0，已完成 | 联合模型的内容通路是否退化 | 审计两个编码器和门控，不训练 | 旧 E9 初始／最佳／末轮 | 保存证据，进入 M1 |
| M1，本轮 | 耦合 L2 是否压制了新闻／财报编码器 | Adam 换 AdamW，所有可训练参数仍 wd=0.01，lr=0.001 | 旧 E9；另对照旧 E7、E8、E6 | 先恢复内容敏感性，不因门控非零就宣布融合有效 |
| M2，本轮 | 参数分组能否改善训练 | 仅改为矩阵权重衰减，偏置／门控免衰减 | M1 | 最多这两个固定优化器配置，不同时调整隐藏维度、输入或 dropout |
| M3 | 联合收益是否超过最好的单模态 | 同架构／优化器下分别重新训练“仅新闻”“仅财报”，与联合模型比较 | 匹配行情权重、预先固定各分支初始化的三组 | 联合必须超过两种单模态；单分支关闭诊断不能替代这些重训对照 |
| M4 | 两分支同时训练是否发生干扰 | 仅改变训练顺序：先分别训练分支，再冻结编码器，只联合训练门控和残差头 | M3 从相同预训练分支出发并同时允许编码器更新的对照 | 控制初始权重相同；若无改善，不添加更复杂交互网络 |
| M5 | 模型是否过度依赖一种模态 | 只将按样本模态 dropout 从 0.1 提到 0.3 | 上一步候选 | 固定行情、结构、优化器、初始化，若开发无改善就恢复 0.1 |
| M6 | 新闻数量、报表存在信息是否冒充内容收益 | 同一候选的内容置零／同股票时间打乱；必要时做一组内容全部屏蔽的重训对照 | 完整内容模型与仅覆盖／缺失信息模型 | 若内容无增量，结果只能称“覆盖特征或偏置”，停止宣称多模态语义有效 |
| M7 | 模态互补能否跨种子与开发时段重复 | 一个固定候选复验种子 42／43／44，不再调结构 | 同条件最佳单模态与 E6 | 联合不优于最佳单模态则删除无效分支，结束本系列 |

M1/M2 固定最多 20 轮，patience=6，min_delta=1e-5，batch=1024，MAE＋0.2 MSE、梯度裁剪 1.0。原始学习率与结构不变，保留 epoch 0 的纯行情状态作为早停候选。

## 各阶段如何判断

第一轮 seed42 的较强对照在运行前固定为旧 E6／E7／E8／E9 同种子的最低开发 MAE。后续若 E8 或新闻单模态有新的开发集合格版本，在启动新阶段之前登记其权重和配置哈希，再固定该对照；不能看完新阶段结果后更换父对照。

初筛要求开发 MAE 改善至少 **0.1%**，MSE 恶化不超过 **0.5%**。进入三种子复验前，至少一个内容分支的置零及对应同股票时间打乱，均须使 MAE 恶化至少 **1e-5**；否则仅记录整体指标，不声称内容增量。最终若声称“互补”，两个分支的重训／消融证据都要支持，而且联合模型要优于最佳单模态。

复验要求至少 2/3 个种子改善，平均 MAE 改善至少 0.1%；等权平均不挑种子。分别报告开发集较早和较晚时段、无新闻／低覆盖／高覆盖组、报告年龄组、第 1/6/12/24 天误差，避免总体均值掩盖某一时段或覆盖组的退化。

门控较大不证明模态有用；门控变化与输入变化引起的预测差异、内容置零、重训对照需要一起看。

## 预算和停止规则

整个 E9 系列最多 **8 个新 seed42 配置**：M1/M2 共 2 个，M3 两个单模态对照，M4 两个匹配初始化的训练策略对照，M5 一个 dropout 候选，M6 预留一个内容屏蔽对照。若 M3 已表明双模态没有优势，就不盲目运行全部后续阶段。

只有通过初筛的一个候选增加 seed43/44。若跨种子失败，就将结果与失败原因保留，不重新挑种子、改变融合权重或继续观察测试分数。

原 E9 “关闭新闻”在已知内部测试集上的数字较低，但开发集不优于 E6，不能据此把它选成新模型。本系列的模型选择始终只根据开发证据。

## 文件与记录

每个编号独立保存 `results/<编号>/`、`outputs/<编号>/`。记录两个门控、编码器／输出头范数、分支输出量级、内容和时间消融、父对照哈希以及保留／停止原因。旧 E9 不覆盖，根模板和其他同学的 E2–E5 不修改。
