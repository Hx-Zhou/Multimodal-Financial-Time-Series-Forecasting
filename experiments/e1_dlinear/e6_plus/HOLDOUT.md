# E6＋E7 冻结模型的留出测试（2026-10-31）

**E6 平稳化模型的固定等权平均在这个留出时间段略优于原 E1；E7 加新闻后反而明显退步。** 这是对开发阶段已经选定的配置做测分，没有重新训练、调参或按测试分数挑种子。

## 固定的评估方案

- E6 使用开发集预先选中的 `stationary` 表示及种子 42、43、44 的既有最佳检查点。
- E7 使用对应的三个冻结行情＋新闻检查点；逐元素核对其行情权重与匹配 E6 完全相同。
- 两组均报告三个种子的全部成绩和固定等权预测平均，平均成员与权重不根据测试结果变化。
- 同时重算 E0、原增强 E1。两者成绩与此前 E1 留出记录一致，原 E1 权重没有改变。
- 测试集仍为组内从官方验证集划出的 15,390 条 holdout，810 只股票、19 个预测起始日（2024-01-24～2024-02-27），目标最晚到 2024-03-29。它已在 E1 阶段揭示，不是新的盲测或课程官方隐藏测试。

## 主要结果

标准化 Close 尺度，越低越好：

| 模型 | 测试 MAE | 测试 MSE |
| --- | ---: | ---: |
| E0 最后值 | 0.354286273 | 0.330339770 |
| 原增强 E1 | 0.351293967 | 0.324071664 |
| E6 平稳化，固定三种子预测平均 | **0.350345190** | **0.320200742** |
| E7 加新闻，固定三模型预测平均 | 0.358695996 | 0.328663776 |

- E6 平均相对 E0：MAE/MSE 降低 **1.1124% / 3.0693%**。
- E6 平均相对原 E1：MAE/MSE 降低 **0.2701% / 1.1945%**。
- E7 平均相对匹配 E6：MAE/MSE **恶化 2.3836% / 2.6430%**。
- E7 平均相对原 E1：MAE/MSE **恶化 2.1071% / 1.4170%**。
- E7 相对 E0 的 MAE 更差、MSE 略好，不能把它概括为全面优于 E0。

E6 是线性模型，固定预测平均可等价合并线性权重；本次直接按三个模型的预测取平均。E7 有非线性新闻 MLP，按当前实现需要运行三个模型。这里的平均预测指标不同于下面的“各次指标均值”。

## 三个种子的完整结果

| 种子 | E6 MAE | E6 MSE | E7 MAE | E7 MSE |
| --- | ---: | ---: | ---: | ---: |
| 42 | 0.352717895 | 0.322526802 | 0.366082779 | 0.336925914 |
| 43 | 0.352528509 | 0.321931653 | 0.356626443 | 0.325707564 |
| 44 | 0.347870767 | 0.318197566 | 0.355763429 | 0.326097499 |
| 指标均值 | 0.351039057 | 0.320885340 | 0.359490884 | 0.329576992 |
| 标准差（ddof=0） | 0.002241653 | 0.001916011 | 0.004674470 | 0.005198910 |

三个种子加入新闻后，MAE/MSE 都比各自 E6 更差。E6 相对原 E1 的 MAE 改善并非每个种子都有：42、43 较差，44 较好；不根据测试成绩改选 seed 44 作为新方案。

## 新闻语义与覆盖分组

测试前固定的诊断是将 MLP 的 8 维语义输出置零，保留新闻数量和存在掩码：

| E7 三模型平均 | MAE | MSE |
| --- | ---: | ---: |
| 正常输入 | 0.358695996 | 0.328663776 |
| 语义置零 | 0.358695958 | 0.328663698 |

差异只有约 3.8e-8 / 7.8e-8，未观察到有意义的语义收益，与开发集诊断一致。这不证明所有新闻方法无效，只限定于本次配置。

按当前模型实际使用的交易日去重新闻数量分组：

| 样本组 | 样本数 | E6 平均 MAE | E7 平均 MAE |
| --- | ---: | ---: | ---: |
| 无新闻 | 106 | 0.451093 | 0.451093 |
| 低覆盖 | 7,832 | 0.345593 | 0.347554 |
| 高覆盖 | 7,452 | 0.353907 | 0.369092 |

无新闻时严格回退 E6，已逐元素核对。高覆盖组的退化更明显；分组是描述性结果，不作为新的选模依据。

## 如何理解开发集与测试集的差异

E6 固定平均在开发集为 MAE/MSE **0.218733 / 0.132215**，弱于原 E1 的 **0.216052 / 0.130342**；在这段 holdout 上排序反转。因此 E6 有局部正面结果，但还不能说稳定超过原 E1，也不能只因这次测试分数更好就反向挑配置。

E7 在开发集上三个种子都改善匹配 E6，在 holdout 上却三个种子都退步。这说明本次新闻分支的开发集收益未泛化到这个留出时间段；可能涉及开发集选择的过拟合或时段变化，现有实验不能区分原因。当前结果不支持采用这版 E7 替换纯行情模型。

窗口之间有重叠，股票共享市场日期；这些样本不是独立重复试验，不作统计显著性声明。本次没有按测试结果继续训练或修改任何配置，后续也不能将已经揭示的数据重新称为新独立测试。

## 复现和校验

实际命令（仓库根目录）：

```powershell
./.venv/Scripts/python.exe -u -m experiments.e1_dlinear.e6_plus.evaluate_holdout --package-dir ../../hs300_train_val
```

评估前保存候选列表、权重摘要和协议；训练期预处理重算后要求与既有记录完全一致，再核对六个模型的开发成绩复现。额外检查 holdout 映射与固定读取器一致、E0/E1 与旧成绩一致、NumPy 指标与独立 PyTorch 归约一致、评估前后权重摘要不变。

结果在 `results/holdout/`：
- `protocol.json`：测分前固定的候选、策略、源文件及权重摘要。
- `summary.json`：全部种子、固定平均、分期限、语义诊断和改进比例。
- `news_coverage_groups.json`：新闻覆盖分组。
- `per_stock.csv`：E0、E1、E6 平均、E7 平均的逐股票结果。

原始冻结权重和本次预测留在本地 `outputs/`，未上传 Git。脚本拒绝覆盖既有结果；同一检查点的复算需同时指定新的 `--output-dir`、`--results-dir`。旧开发 JSON 中的 `holdout_evaluated: false` 保留当时事实，本次独立记录为 `true`。
