# DLinear 扩展：E6 行情表示＋E7 新闻增量

本目录是独立的 **DLinear 扩展支线**，不代表团队已将 DLinear 选为 E1–E5 中最佳数值骨干。原 E1 代码、权重、结果及公共切分保持不变。工作分支为 `experiment/dlinear-e6-plus`。

**本轮已完成 E6 两组各三种子、E7 三种子及新闻消融。结论：暂不建议用这版扩展替换原增强 E1。** E6 原始/平稳化的开发 MAE 均值为 0.219677 / 0.219577，E7 为 0.218199；新闻对匹配 E6 有小幅改善，但语义置零后指标几乎不变。E7 三模型预测平均为 MAE 0.217032、MSE 0.131258，仍弱于原 E1 的 0.216052 / 0.130342。详见 [RESULTS.md](RESULTS.md)。

开发阶段没有使用 holdout。后续固定模型的留出测试已完成，见 [HOLDOUT.md](HOLDOUT.md)：E6 固定平均在该时段比原 E1 的 MAE/MSE 好 0.27% / 1.19%，但 E7 比匹配 E6 恶化 2.38% / 2.64%，三个种子均退步。E6 的开发与留出排序不一致，尚不能说稳定超越原 E1；本次没有据测试结果调参或改选种子。

14 项数值检查通过；两次执行性能修复前后，seed 43 已记录的第 0～7 轮 MAE/MSE 完全一致。所有正负结果、消融和中断日志都保留。

## 对照设计

E6 比较相同的七变量 DLinear，仅改变行情表示：

| 项目 | A：原始七字段 | B：平稳化七特征 |
| --- | --- | --- |
| 价格 | Open、High、Low、Close | 对数收益、(High-Low)/Close、(Close-Open)/Open、标准化 Close |
| 其他 | Volume、Dividends、Stock Splits | log1p(Volume)、分红事件、拆股事件 |
| 标准化 | OHLC 使用原训练期 Close 均值/标准差；其他三字段使用训练输入日统计量 | 价格水平使用原统计量；收益、振幅、开收差、对数成交量使用训练输入日统计量 |
| 中心化 | 四个价格字段减去当前窗口末日 Close | 价格水平减去窗口末日 Close |

额外统计量只用训练样本覆盖的**去重输入日**拟合，不使用开发或留出测试的数据分布。对数收益只使用当前及前一日；每个输入窗口第一日收益强制为零（再按训练统计量转换），不要求窗口之外的输入。

两个 E6 模型均为窗口 25 的趋势/剩余项分解、七通道展平后的两层线性输出，32,304 参数。输出为 `最后一日标准化 Close + (h/24) × 预测残差`，h=1…24。此处 h/24 在训练和推理中均固定使用。与旧 E1 的“训练后收缩＋权重平均”流程不同，**不能把 E6 对旧 E1 的差异全部解释为单一特征收益**；严格的输入对照是这里 A 与 B 的比较。

使用种子 42、43、44 对 A、B 各训练一次，按三种子开发 MAE 均值选表示；差异不超过 1e-5 时保留简单的 A。MAE 选模型，MSE 同时完整报告。

## E7：固定行情的新闻增量

固定 E6 选中的表示，并分别冻结对应种子的 E6 行情权重。每天的 512 维新闻按 `vector_id` 去重后均值池化，通过可训练的 `512→8→8` 小型 MLP，再乘新闻存在掩码。与 `has_news` 和 `log1p(news_count)` 一起形成十维每日新闻输入。

新闻输入使用同样的 DLinear 分解和线性读出，以残差形式加入数值预测。这等价于在同一线性读出中扩展输入通道，同时固定原行情通道的系数。是 **TaTS 式、冻结行情的新闻对照**，不是 TaTS 论文的完整复现，也没有使用 GPT-2。

- 按固定读取器的交易日历日归桶；非交易日新闻不纳入本版，未把周末新闻提前放到前一交易日。
- MLP 后再次乘存在掩码；整个窗口无新闻时，新闻修正严格为零，即使分支存在偏置。
- 新闻头零初始化；E7 第 0 轮恰好等于对应 E6。早停候选包含第 0 轮，若新闻无收益则如实报告回退。
- E7 共 82,608 参数，其中固定行情 32,304、可训练新闻部分 50,304。
- 另报开发集新闻语义置零、同股票内窗口新闻置换，以及无新闻/低覆盖/高覆盖组的配对 E6、E7 误差。语义置零发生在 MLP 之后，将 8 维语义输出归零，保留存在掩码和数量；置换检查属于破坏性诊断，不用于训练或选择新配置。

E7 与**匹配种子、相同表示、相同行情权重**的 E6 比较。收益不能只与 E0 或较弱的旧版 E1 比较。

## 训练与数据边界

复用原读取器与公共时间切分：587,587 条训练样本、42,930 条开发样本，18,630 条边界样本排除。15,390 条 holdout 不参与训练或配置决策，固定模型后另行测分。旧 E1 的 holdout 已经公开，不能再将它作为这轮扩展的全新独立证据。

固定 Adam 学习率 0.001、L2=0.01、batch=1024、最多 40 轮、patience=6、min_delta=1e-5、梯度裁剪 1.0，损失为 MAE+0.2×MSE。E6 至少训练一轮；E7 显式保留第 0 轮。

每天的数值表按批次构造 96 日窗口；新闻按天池化并缓存到本地磁盘，只在批次内投影不同的新闻日，避免展开全部新闻窗口。数据、缓存和权重留在 `outputs/`，不提交 Git。

## 运行

在仓库根目录：

```powershell
./.venv/Scripts/python.exe -m unittest experiments.e1_dlinear.e6_plus.test_extension -v
./.venv/Scripts/python.exe -u -m experiments.e1_dlinear.e6_plus.run --package-dir ../../hs300_train_val --stages e6-e7
./.venv/Scripts/python.exe -m experiments.e1_dlinear.e6_plus.report --package-dir ../../hs300_train_val
```

结果目录已存在时拒绝覆盖。复现请同时指定新的 `--output-dir` 和 `--results-dir`。仅运行 E6 时使用 `--stages e6`。

训练前写入 `results/protocol.json`，数据处理后保存 `data_protocol.json`；逐轮日志及每个种子的正负结果均保留。总体及分期限指标使用与旧 E1 相同的双精度误差计算。训练全部完成后，`report.py` 用保存的开发预测生成 [RESULTS.md](RESULTS.md) 和逐股票表，不重新训练或评估 holdout。测试覆盖训练统计不受未来数据影响、特征因果性、无新闻严格回退及新闻训练不改变数值权重。

检查点包含表示名称、新闻开关和 `state_dict`，配合 `results/data_protocol.json` 的标准化参数恢复。本目录目前是实验入口，尚未封装为课程最终提交接口。

本机首次运行到 E7 seed 43 时，发现固定读取器的 `_reports` 方法缓存会继续引用数据集实例和整套新闻矩阵，导致内存紧张、训练变慢。已在扩展加载器中释放该缓存，未修改公共读取器或任何模型/特征设置。修复前代码与已完成结果保留在提交 `42aa683`；中断种子的已见日志另存 `results/interruption.json`，本地输出归档到 `outputs/interrupted_e7_stationary_seed43/`。

`--resume` 会核对原协议、数据处理统计量和已完成检查点摘要，只跳过完整且一致的运行。未完成目录需先明确归档，不能静默覆盖；本次续跑的来源记录在 `results/resume_protocol.json`。旧 E6 和 E7 seed 42 的结果没有重训或改写。
