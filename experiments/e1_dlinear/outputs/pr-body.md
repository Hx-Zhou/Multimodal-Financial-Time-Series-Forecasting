本 PR 交付 E1：仅使用过去 96 日 Close 的 DLinear 实现、可复现训练流程及开发验证结果。原版没有超过 E0；保留原版及未获提升的实验记录，并提供带中心化、正则化、按预测期限收缩残差和权重平均的改进候选。

**交付定位是线性基线对照，而非已经证明显著提分的方案。** 增强版开发集收益不足 1%，且经过多轮开发集选择，尚未证明明显、可靠的独立测试收益。合并此 PR 不代表选定 DLinear 为最终骨干；E2–E5 应继续与 E0 及明确标注预处理的 E1 结果公平比较。此定位已写在 E1 README 开头。

## 开发验证结果

使用 587,587 条训练样本和既定的 42,930 条开发验证样本，排除 18,630 条标签重叠边界样本。以下 MAE/MSE 均为标准化 Close 尺度：

| 模型 | MAE ↓ | MSE ↓ |
| --- | ---: | ---: |
| E0 最后值（已复现） | 0.217307 | 0.131206 |
| 原版 DLinear，三种子指标均值 | 0.235596 | 0.146163 |
| 改进候选，平均权重后的单模型 | **0.216052** | **0.130342** |

改进候选相对 E0 的 MAE/MSE 分别降低约 **0.58% / 0.66%**。固定残差收缩规则后，种子 42、43、44 的两项指标均改善；权重平均后仍是单个 4,656 参数 DLinear，推理不需要运行三个模型。

这些结果来自多轮选择所使用的同一个开发集，不代表独立测试收益。保留的 15,390 条 holdout **尚未评估**，应由团队在最终方案确定后统一验证。部分样本组仍有退化，详见报告。该 PR 是 E1 实验交付，尚不是课程最终模型提交。
