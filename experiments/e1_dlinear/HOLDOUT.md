# E1 固定最终模型的留出测试（2026-10-31）

**冻结的增强版 E1 在组内留出测试集上小幅超过 E0：MAE 降低 0.8446%，MSE 降低 1.8975%。** 本次没有训练、修改超参数、重新选择种子或根据测试结果调整模型。可以报告“在这个留出时间段上有小幅收益”，不能据此声称显著提分或跨时期稳定优势。

## 评估对象和数据

- 模型就是此前开发集选定的中心化 DLinear：窗口 25、Adam L2=0.01、种子 42/43/44、残差按 h/24 收缩后等权平均权重，仍为 4,656 参数的单模型。
- 直接加载本地 `outputs/calibration/model.pt`；SHA-256 为 `db947e6b959982d2490cabfc230301bf2e347d9c713d40821cf86f1574b0cf83`，与此前已提交的 `results/calibration/summary.json` 完全一致。收缩已折入权重，没有重复乘系数。
- 测试集是从官方验证集按原公共规则切出的组内 holdout，不是课程官方隐藏测试集。共 15,390 条样本、810 只股票、19 个预测起始日，起始日为 2024-01-24～2024-02-27，标签最晚到 2024-03-29。
- 开发集标签最晚到 2024-01-23；原有 18,630 条边界样本仍排除。未修改公共切分、固定读取器或根目录模板。
- E0 和 E1 使用完全相同的样本、训练期标准化参数和标签。MAE/MSE 在全部样本及 24 个预测位置上等权计算；数值越低越好。

## 结果

| 模型 | 测试 MAE ↓ | 测试 MSE ↓ |
| --- | ---: | ---: |
| E0 最后值 | 0.354286273 | 0.330339770 |
| 最终增强版 E1 | **0.351293967** | **0.324071664** |
| E1 相对降低 | **0.8446%** | **1.8975%** |

相对降低定义为 `100 × (1 - E1 / E0)`。MAE 绝对减少 0.002992306，MSE 绝对减少 0.006268106，均为标准化 Close 尺度，不是交易收益率。

## 结论边界

1. 本次结果提供了开发集之外的正面证据，因此当前结论应更新为“增强版在开发集与这个留出测试时间段均有小幅收益”。原版的开发集负结果仍保留；不能把增强版收益全部归因于原始 DLinear 结构。
2. 这不是过拟合不存在的证明。测试窗口有重叠，股票共享市场日期，15,390 条样本不是同等数量的独立观测；只有一个较短的留出时间段，没有进行统计显著性推断。
3. 本次只测试预先选定的最终候选，不对原版、其他候选或种子逐一测分后再挑赢家。今后不据此继续优化 E1；若继续调整，需要新的未使用评估数据。
4. 该 holdout 现在对 E1 已经揭示。团队应知晓这一点，E2–E5 仍只在开发集调参，固定方案后再做留出评估；不能反复查看该测试集来选择新配置。

## 复现和核对

`evaluate_holdout.py` 在计算测试指标前写入协议，核对最终权重、验证数据摘要和公共切分，再使用原数据处理及指标实现。使用固定读取器抽查输入和标签一致性，并以独立 PyTorch 归约核对 NumPy 的 MAE/MSE。E0 重算结果与公共 E0 报告在浮点精度范围内一致。已有 10 项数值测试全部通过。

实际执行命令（仓库根目录）：

```powershell
./.venv/Scripts/python.exe -u -m experiments.e1_dlinear.evaluate_holdout --package-dir ../../hs300_train_val
```

已有结果目录会拒绝覆盖。复现本次测分需使用上述原始冻结检查点（权重不随 Git 上传，本机仍保留），并指定新的 `--results-dir experiments/e1_dlinear/results/holdout_reproduction`；脚本要求权重摘要匹配原开发集记录，不接受临时改选的模型。从头复训的文件摘要不保证一致，不能直接替代本次冻结检查点。重复计算仅用于核验，不用于调参。

记录文件：

- `results/holdout/protocol.json`：评估前固定的方案、权重/数据/代码摘要及切分。
- `results/holdout/summary.json`：总体及分期限成绩、相对改进和评估时间。
- `results/holdout/e0_per_stock.csv`、`e1_per_stock.csv`：全部逐股票成绩。
- `results/holdout/news_coverage_groups.json`：描述性新闻覆盖分组。

先前开发实验 JSON 中的 `holdout_evaluated: false` 是当时的真实状态，保留原样；本次记录使用 `holdout_evaluated: true`。
