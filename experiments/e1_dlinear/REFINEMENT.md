# E1 第三轮：稳定求解、残差收缩与权重平均（2026-10-29）

**本轮得到在开发验证集上优于 E0 的候选：中心化 DLinear + L2 + 按期限收缩残差 + 三种子权重平均。** 单个种子使用固定收缩规则后，三个种子的 MAE/MSE 均优于 E0；平均权重后的单个模型进一步小幅改善。独立 holdout 尚未评估。

| 模型 | 开发 MAE | 开发 MSE |
| --- | ---: | ---: |
| E0 最后值 | 0.217307 | 0.131206 |
| 原版 E1，种子指标均值 | 0.235596 | 0.146163 |
| 第二轮中心化 + L2，种子指标均值 | 0.217069 | 0.131303 |

最终单模型相对 E0 的 MAE 降低 **0.5773%**、MSE 降低 **0.6586%**。幅度较小，结论限定为当前开发验证集上的改善。

## 1. 稳定求解与近期加权：未带来提升

固定中心化与窗口 25 后，DLinear 的分解和预测均为线性运算。因此先构造趋势、剩余项和截距的特征矩阵，在全部训练样本上求带 L2 的解析最小二乘解。两层偏置合并求解后再均分回两层，保留原模型的参数范数含义。

预先固定 12 组配置：均匀训练权重、训练日期半衰期 252 或 126 的近期加权，各配正则化 0.001、0.01、0.1、1.0。日期权重只根据训练集的预测起始日期排序计算。先后用均匀权重及近期加权中的最佳候选，继续全量优化平滑 MAE + 0.2 MSE，平滑尺度固定 0.001。

解析解的训练损失是 MSE，全量稳健优化使用平滑 MAE + 0.2 MSE。这两个扩展实验与原 Adam 训练的损失/优化设置有区别，单独记录，不能当作仅修改学习率的对照。该轮 L2 按每个预测位置归一化，其系数也不能直接与 Adam `weight_decay` 数值比较。

| 代表配置 | 开发 MAE | 开发 MSE |
| --- | ---: | ---: |
| 均匀权重，解析解 λ=1 | 0.222816 | 0.134532 |
| 近期加权 252，解析解 λ=1 | 0.223354 | 0.134729 |
| 近期加权 126，解析解 λ=1 | 0.223531 | 0.134651 |
| 均匀权重，全量稳健优化 λ=1 | 0.218617 | 0.132316 |
| 近期加权 252，全量稳健优化 λ=1 | 0.219249 | 0.132651 |

这些配置都没有超过 E0。最佳稳健解的预条件梯度最大值约为 5.35e-7，说明该训练目标已得到较充分优化，但训练目标的进一步优化未转化为开发收益。本分支的全部正负结果保存在 `results/refinement/`，不选用其权重。

## 2. 按预测期限收缩残差

第二轮的第 24 天预测改善，而较短期限经常变差，因此检查短期是否被模型过度修正。以第二轮固定的中心化、窗口 25、Adam L2=0.01 模型为基础，预先固定四条曲线，不自由学习 24 个验证期系数：

| 残差系数 g(h)，h=1…24 | seed 42 MAE | seed 42 MSE |
| --- | ---: | ---: |
| 1：保持原预测 | 0.216983 | 0.131187 |
| 0.5：全部期限减半 | 0.216191 | 0.130231 |
| h / 24：线性递增 | **0.215895** | 0.130197 |
| (h / 24)²：平方递增 | 0.215897 | 0.130146 |

预测形式为 `最后一日 Close + g(h) × 原预测残差`。选配置只使用 seed 42 的开发 MAE，并要求候选同时改善 E0 的 MAE/MSE；按事先保存的规则选中 `g(h)=h/24`。线性与平方曲线的差距很小，不能据此断言线性曲线普遍更优。

这个规则让第 1 天只保留 1/24 的修正，第 12 天保留一半，第 24 天保留全部修正。它直接乘入两层输出权重及偏置的对应行，推理仍使用原 DLinear 类。

权重平均后的单模型 MAE/MSE 为 **0.216052289 / 0.130342100**。这是单模型实际计算出的指标，与上一行“各次运行指标的均值”含义不同。

本项目已在同一开发集上进行多轮选择。三个种子一致改善描述的是优化过程的稳定性，不能证明未来时间段上的收益；团队最终确定方案后仍需使用保留的 holdout 做独立评估。本轮未查看 E1 holdout 分数。

## 5. 当前推荐候选与复现

最终本地检查点：`outputs/calibration/model.pt`。其中 `config` 为 `moving_average=25, center_last=True`，`state_dict` 已包含残差收缩及平均权重。恢复时直接使用保存的配置，**不要再额外乘一次 h/24**。

先复现源模型的三个种子，再进行收缩规则选择与权重平均。以下命令在仓库根目录运行：

```powershell
./.venv/Scripts/python.exe -u -m experiments.e1_dlinear.run --package-dir ../../hs300_train_val --kernels 25 --seeds 42 43 44 --center-last --weight-decay 0.01 --output-dir experiments/e1_dlinear/outputs/reproduce_source --results-dir experiments/e1_dlinear/results/reproduce_source
./.venv/Scripts/python.exe -u -m experiments.e1_dlinear.calibrate --package-dir ../../hs300_train_val --source-dir experiments/e1_dlinear/outputs/reproduce_source --output-dir experiments/e1_dlinear/outputs/reproduce_final --results-dir experiments/e1_dlinear/results/reproduce_final
```

如需复现未获提升的解析解与全量优化分支：

```powershell
./.venv/Scripts/python.exe -u -m experiments.e1_dlinear.refine --package-dir ../../hs300_train_val --output-dir experiments/e1_dlinear/outputs/reproduce_refinement --results-dir experiments/e1_dlinear/results/reproduce_refinement
```

10 项数值检查通过，覆盖原模型接口、旧权重兼容、解析解的驻点条件、全量目标下降、期限收缩与权重平均的等价性。最终检查点重新加载后的预测也与保存前逐元素一致。所有实验保持在 `experiments/e1_dlinear/` 内，根目录提交模板、固定读取器和公共时间切分保持原样。
