# E10：DLinear＋SpecTF-style 新闻频域融合

本目录只保存 E10。冻结与 E7 相同的 E6 stationary 行情分支，使用已有 512 维新闻向量，不使用财报或 GPT-2。

**已完成结果：**三种子等权预测的开发 MAE **0.218590918**，内部测试 MAE **0.350691397**。虽然测试优于原 E7 的 **0.358695996**，但仍差于 E6 的 **0.350345190**（差约 **0.0988%**），且开发集没有超过 E7。新闻语义置零不改变测试指标，没有稳定收益支持采用此频域版本。完整结果见 [RESULTS.md](RESULTS.md)。

这是项目路线下的**简化 SpecTF-style 适配**，不是完整论文复现：

1. 行情沿 96 天维度做 rFFT，固定取直流及前 12 个频率，实／虚部投影到 8 个复数通道。
2. 每日去重均值新闻通过 512→8→16 MLP 表示复数实／虚部；保留新闻数量／存在信息，并使用时间相位编码。
3. 行情频率 query 对每日新闻 key/value 进行交叉注意力，使用复内积实部作为分数；无新闻日显式掩码。
4. 补零至完整频谱、逆 FFT 返回 96 天表示，再由 DLinear 零初始化头预测 24 维新闻残差。
5. 小门控与模态 dropout；整个窗口无新闻时严格回到 E6，epoch 0 也等于 E6。

主要比较 E7 的简单 TaTS-style 新闻扩展，同时列出 E6 纯行情结果。训练前固定频率数、宽度及种子，没有依照测试成绩调整结构。相对旧 E7，本版本同时带有门控和模态 dropout；这是预先指定版本之间的对照，不能把指标差异全部归因于频域操作，也不能替代严格控制其他因素的融合方式消融。

## 运行与记录

仓库根目录：

```powershell
./.venv/Scripts/python.exe -u -m experiments.e10_dlinear_spectf.run --package-dir ../../hs300_train_val --evaluate-holdout
```

已有运行用 `--resume` 保留记录并继续。完整规则见 [公共工具说明](../dlinear_modal_common/README.md)。

本目录 `results/` 保存训练前协议、每个种子的曲线、开发集／内部测试集指标、新闻语义置零、开发集时间打乱、新闻覆盖分组及逐股票误差。`outputs/` 保存本地权重和预测，不上传 Git。结果见 [RESULTS.md](RESULTS.md)。
