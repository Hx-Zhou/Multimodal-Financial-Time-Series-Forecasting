# DLinear 多模态实验公共工具

这里只存放数据预处理、训练／评估调度和正确性检查。三个实验分别位于：

- `../e8_dlinear_reports/`：行情＋财报。
- `../e9_dlinear_multimodal/`：行情＋新闻＋财报。
- `../e10_dlinear_spectf/`：行情＋新闻的简化频域交叉注意力。

每个目录独立保存 `model.py`、`run.py`、`README.md`、`RESULTS.md`、`results/` 和本地 `outputs/`。公共 `outputs/` 只缓存相同的数据表，已被仓库的 gitignore 排除。原 E1、E6/E7 的历史目录和模型不变，不修改根目录 `model.py`、`hs300_dataset.py` 或公共划分。

## 一次运行全部实验

在仓库根目录执行：

```powershell
./.venv/Scripts/python.exe -u -m experiments.dlinear_modal_common.run --package-dir ../../hs300_train_val --evaluate-holdout
```

全部开发集训练和诊断结束后，程序为所有候选写入权重哈希，再构建内部 holdout 样本并计算指标。公共读取器在准备阶段会载入整个 `val.npz`，但训练和早停只取得开发子集；holdout 不进入优化或模型选择。已有记录不会静默覆盖；中断时可加 `--resume`，它校验代码、超参数、数据处理和行情权重，保留已完成运行，从未完成运行的最近完整 epoch 恢复模型、优化器和随机状态。复现实验应使用独立 checkout／目录，保留原始结果；所需本地 E6 权重须先按旧实验说明生成。

```powershell
./.venv/Scripts/python.exe -m unittest experiments.dlinear_modal_common.test_integrity
```

## 统一协议

- 冻结 E6 开发集选出的 `stationary` 行情权重，种子固定 42、43、44；不按 holdout 挑 seed44。
- 每个模型只训练辅助分支；初始零残差与匹配 E6 相同，epoch 0 可以被早停选中。
- Adam，lr=0.001，L2=0.01，batch=1024，最多 40 epoch，patience=6，min_delta=1e-5，梯度范数限制 1.0。
- 损失 MAE＋0.2 MSE；主结果为三个种子预测的等权平均，另外报告单种子指标的均值与标准差，两者不能混用。
- 小门控 sigmoid(-2)，按样本进行概率 0.1 的模态 dropout。
- 内部测试集沿用 15,390 样本，不用于早停、超参数选择、延迟选择或种子选择。这一时间段此前已用于 E1/E6/E7 检查，不能称为新的盲测或官方隐藏测试。
- 窗口重叠，同一市场日期相关；没有把 15,390 行当作独立样本计算显著性。

## 财报时间与历史版本限制

源数据缺少公告日期。固定主设置为报告期末＋180 个自然日，输入最后一天达到该日期才允许使用。若未来数据有真实 `ann_date`／`f_ann_date`，优先使用实际日期；重复报告取较晚可用日，字段数值冲突时掩码缺失，不按 JSON 行顺序选择修订值。

敏感性检查将可用性再延后 90 天（270 天），**使用原训练统计量和冻结权重，不重训、不挑延迟**。这是一项可用性压力测试，不能替代真实公告时间或原始发布版本。统一 180 天也会舍弃部分当时已经公开的较新报表，因此结论仅适用于本可用性假设。数据可能含事后修订；即使延迟保守，也不能证明严格 point-in-time 无泄漏。

数值字段包括三个报表各四个关键字段，以及同季度同比变化、显式缺失掩码、报告年龄和表存在掩码，共 54 维。只有训练样本输入截止点参与统计量拟合；验证／测试不参与。字段量级用 signed-log 处理，同比用有界对称变化率，以适配负利润和累计年度口径。270 天检查不重新拟合标准化。

## 归因边界

这是用户指定的 **DLinear 扩展**，未宣布它是全组 E1–E5 的最佳骨干。

E9 相对旧 E7 还加入了门控、模态 dropout 和联合训练，因此二者的差异不能全部归因于财报。E9 保存同一权重下关闭单个分支的诊断，但它也不能替代单模态重训对照。

E10 是遵循项目路线的轻量 SpecTF-style 适配：13 个低频模式、8 个复数通道的交叉注意力，无 GPT-2；没有声称完整复现论文。它相对旧 E7 也带有新增门控／dropout，比较的是整个预先指定版本，不能据此孤立推断频域操作的因果收益。
