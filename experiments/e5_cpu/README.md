# E5 iTransformer 结果

在全部行情变量（平稳化特征）上运行 iTransformer，验证「变量间注意力」是否优于 GRU 的隐式多变量建模。

## 运行

```bash
python -m experiments.e5.e5_itransformer \
  --epochs 10 --patience 3 --batch-size 256 --seed 0
```

脚本不改写 `data/*.npz`，按 `target_start_date` 时间顺序切分官方验证集（复用 `experiments/validation_split.py`）：

| 部分 | 样本数 | 预测起始日期 |
| --- | ---: | --- |
| 开发验证集 | 42,930 | 2023-10-09 至 2023-12-20 |
| 排除的边界样本 | 18,630 | 2023-12-21 至 2024-01-23 |
| 留出测试集 | 15,390 | 2024-01-24 至 2024-02-27 |

## 模型与输入

- **架构**：iTransformer，每个变量作为一个 token，注意力作用于变量间而非时间步间；`Close` token 投影到 24 步残差，再加最后一天标准化收盘价 `z_96`（残差输出 `ŷ_h = z_96 + Δ_h`）。
- **输入特征**（平稳化，E6-B 方案，`[96, 10]`）：
  1. `z_close`、`z_open`、`z_high`、`z_low`：价格用 `close_mean/close_std` 转到标签尺度；
  2. `amplitude = (High-Low)/std`、`open_close = (Open-Close)/std`；
  3. `log_ret`（对数收益率）、`log_vol = log(1+Volume)`；
  4. `dividends`、`splits`。
  - 非价格特征（`log_ret/log_vol/dividends/splits`）用训练集统计量做 z-score，统计量见 `input_stats.json`。
- **超参**：`d_model=128`、`n_heads=4`、`d_ff=256`、`n_layers=2`、`dropout=0.1`，参数量 281,752。
- **训练**：`Adam(lr=1e-3)`、梯度裁剪 1.0、损失 `MAE + 0.2×MSE`、24 位置等权、按开发验证集 MAE 早停。
- **残差头零初始化**：让模型从「最后值」基线起步再学增量。

## 结果（标准化尺度）

参照 E0 最后值基线（开发验证集 MAE 0.2173 / MSE 0.1312）。

| 配置 | 最佳轮次 | 开发 MAE | 开发 MSE | 留出 MAE | 留出 MSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| d_model=128, lr=1e-3（路线默认） | 1 | 0.2307 | 0.1528 | 0.3685 | 0.3739 |
| d_model=128, lr=3e-4, wd=1e-4 | 1 | 0.2364 | 0.1598 | 0.3933 | 0.4216 |
| d_model=64, 1 层, lr=1e-4 | 1 | 0.2389 | 0.1529 | 0.3760 | 0.3807 |

分期限（d_model=128, lr=1e-3，最佳轮次）：

| 期限 | 开发 MAE | 开发 MSE |
| ---: | ---: | ---: |
| 1 | 0.0644 | 0.0115 |
| 6 | 0.1651 | 0.0753 |
| 12 | 0.2344 | 0.1469 |
| 24 | 0.3581 | 0.2971 |

## 结论

- **iTransformer（纯行情，全变量）没有超过最后值基线**：残差头零初始化使模型从 E0（0.2173）起步，但仅 1 个 epoch 后开发 MAE 就上升到 0.23 以上，且随训练继续单调变差。
- 训练损失持续下降（0.333 → 0.300）而开发集变差，说明模型在**拟合训练期（2020–2023，含 2020 疫情高波动段）的噪声**，无法迁移到开发期（2023 年末）。降低学习率、加大正则、减小容量均不能改变这一现象。
- 这与「日频股价近似随机游走、最后值接近最优预测」一致。纯行情模态的可学习增量信号非常弱，**真实的增益预期来自新闻与财报（E7–E9）**。

## 下一步建议

1. 与 **E3 多变量 GRU** 做同口径对比（E5 与 E3 只差「变量注意力 vs 隐式多变量」），完成路线中 E3↔E5 的对照判断；两者大概率都 ≈ 最后值。
2. 若纯行情骨干普遍无法超越 E0，按路线尽早转向 E7/E8，把行情骨干固定在「最后值 + 小增量」这一简单方案，把算力留给多模态融合。
3. 可考虑只对**短期限（h≤6）**做增量建模，因 h1 误差（0.064）显著小于 h24（0.358），短期存在稍多的可利用信号。
