# E0 基线结果

运行脚本：

```bash
python -m experiments.e0.e0_baseline \
  --split val \
  --pseudo-test-fraction 0.2 \
  --output experiments/e0/e0_val_results.json
```

脚本不会改写 `data/val.npz`。它按 `target_start_date` 的时间顺序切分官方验证集：最晚的 20% 日期作为留出测试集，开发验证段还会排除标签延伸到测试期的边界样本。

本次切分按预测起始日确定测试段，并从开发验证段排除标签延伸到测试期的边界样本：

| 部分 | 样本数 | 预测起始日期 |
| --- | ---: | --- |
| 开发验证集 | 42,930 | 2023-10-09 至 2023-12-20 |
| 排除的边界样本 | 18,630 | 2023-12-21 至 2024-01-23 |
| 留出测试集 | 15,390 | 2024-01-24 至 2024-02-27 |

开发验证集的标签最晚到 2024-01-23，测试集标签从 2024-01-24 开始，两段标签日期不重叠。

模拟测试集仍然有 `y`，所以它是一个带标签的时间后移评估集，不是最终隐藏测试集。模型选择可以使用调试段，模拟测试集应尽量留到方案确定后再查看。

## 结果

所有预测都在标准化收盘价尺度上进行，预测未来 24 天均使用同一个基准值。

### 开发验证集

| 基线 | MAE | MSE |
| --- | ---: | ---: |
| 最后值 | 0.217307 | 0.131206 |
| 5 日移动平均 | 0.230412 | 0.142225 |
| 10 日移动平均 | 0.246450 | 0.155649 |
| 20 日移动平均 | 0.275334 | 0.180933 |

### 模拟测试集

| 基线 | MAE | MSE |
| --- | ---: | ---: |
| 最后值 | 0.354286 | 0.330340 |
| 5 日移动平均 | 0.378627 | 0.358666 |
| 10 日移动平均 | 0.392914 | 0.381531 |
| 20 日移动平均 | 0.406871 | 0.414519 |

因此当前 E0 的主要参照是“复制输入窗口最后一天的标准化 Close”。移动平均在这次切分中没有超过最后值，不应作为首选基线。

## 脚本行为

`e0_baseline.py` 会：

1. 从 `HS300Dataset` 读取指定切分的 96 天行情和 24 天标签。
2. 使用每只股票的 `close_mean`、`close_std` 将输入 Close 转换到标签尺度。
3. 计算最后值，以及最近 5、10、20 天标准化 Close 的均值。
4. 将最晚一段预测起始日期作为留出测试集，并排除预测标签与测试期重叠的开发样本。
5. 输出总体 MAE/MSE，结果文件只保留主要比较指标。

例如只评估完整验证集：

```bash
python -m experiments.e0.e0_baseline --pseudo-test-fraction 0
```

调整模拟测试集比例：

```bash
python -m experiments.e0.e0_baseline --pseudo-test-fraction 0.1
```

这个切分按日期进行，而不是随机抽样，因此不会把同一日期的不同股票窗口分到两边，能够更接近未来测试的时间外推场景。
