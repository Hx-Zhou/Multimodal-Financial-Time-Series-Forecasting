# E4：Close-only PatchTST 固定配置初筛

本实验单独保存在 `experiments/e4_patchtst/`，使用原完整训练集和共享的开发／内部测试划分。当前只跑一个预先固定配置、seed42，先确认 PatchTST 在本任务中是否值得继续。

## 结构与公平对照

- 输入：96 个标准化 Close；输出：24 个标准化 Close。
- `patch_len=16`、`stride=8`，共 11 个片段，无额外尾部补齐。
- 片段线性投影＋可学习位置编码，2 层 Transformer Encoder，`d_model=128`、4 个头、`d_ff=256`、GELU、pre-LayerNorm、dropout=0.1。
- 片段表示展平后，用零初始化线性头输出残差，初始预测严格等于最后值 E0。总参数 302,616。
- 公共变换：减去输入最后值，除以该输入窗口的标准差 `sqrt(var+1e-5)`；输出乘回标准差与固定 h/24，再加最后值。只用历史输入，不拟合验证／测试统计量。

另外训练一个 4,656 参数的 DLinear 对照，共享输入变换、锚点、h/24、损失、优化器、数据顺序和早停。增强 E1 作为历史强参照，它的优化器、训练后收缩与三种子平均方式不同，不能把与它的差异全部归因于注意力架构。

这是小型 PatchTST-style 实现，使用其片段编码核心，不声称完整复现原论文全部配置。只输入 Close；E2/E3 不运行，新闻和财报不输入模型。

## 首轮固定设置

| 项目 | 设置 |
|---|---|
| seed | 42，仅初筛 |
| 训练上限／patience | 12 epoch／4 epoch |
| 选择指标／min_delta | 开发 MAE／1e-5 |
| 损失 | MAE＋0.2 MSE |
| 优化器 | AdamW，lr=0.0003；二维及以上参数 wd=0.01，一维参数和偏置不衰减 |
| 梯度裁剪 | 范数 1.0 |
| batch／CPU threads | 512／4 |
| 运行环境 | 已有 PyTorch 2.8.0+cpu、NumPy 2.2.6，不新增安装 |

批量／线程仅按合成数据吞吐量选取，没有根据真实开发指标搜索配置。CPU 4 线程、batch512 的短测吞吐约 3,826 样本／秒，完整一轮预计数分钟。

初始 E0 纳入 `selected.pt` 的选择；另外保存实际训练 epoch≥1 中按开发指标选出的 `best_trained.pt`。如果训练后不如 E0，会明确报告回退及实际训练成绩，避免把 E0 伪装成 Transformer 的学习收益。两个权重角色在训练前声明，测试后不更改。

## 数据与评价

- Train：587,587；development：42,930；边界隔离：18,630；内部 holdout：15,390。
- 开发目标起点：2023-10-09 至 2023-12-20；测试目标起点：2024-01-24 至 2024-02-27。
- 只用开发集早停。全部候选及哈希固定后，才构建 holdout 样本统一评分。
- 内部 holdout 此前已多次查看，不是新盲测或官方隐藏测试，不用于本轮调参。
- 主要指标 MAE、MSE；同时保存第 1/6/12/24 天指标。两种指标都在标准化 Close 尺度上计算，越低越好。
- 若首轮不能明显超过增强 E1 与匹配 DLinear 中较强者，不宣称升级；若有改善，仍需后续三种子复验。一次固定配置不能代表整个模型族的上限。

## 运行

在仓库根目录使用已有环境：

```powershell
./.venv/Scripts/python.exe -m unittest experiments.e4_patchtst.test_model
./.venv/Scripts/python.exe -u -m experiments.e4_patchtst.run --package-dir ../../hs300_train_val --evaluate-holdout
```

已有记录不会静默覆盖；中断后加 `--resume`，会核对协议、源文件与数据，并恢复最近完整 epoch 的模型、优化器、随机状态和训练记录。复现新试验应使用独立 checkout／新目录，保留本次结果。

`results/` 保存协议和指标，`RESULTS.md` 保存对比表；`outputs/` 只保存小型权重、恢复状态和预测数组，不写原始数据副本或大型中间缓存。原始 Close 数组只在内存中使用。根模板、公共划分和已有实验均不修改。
