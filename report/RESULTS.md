# E5 实验数据汇总

> 实验：E5 iTransformer（全部行情变量的倒置 Transformer）
> 所有数值均在标准化收盘价尺度上，越低越好。切分复用 `experiments/validation_split.py`。
> 训练日志见 `e5_train.log`，机器生成结果见 `e5_val_results.json`，权重见 `e5_model.pt`。

## 1. 实验设置

| 项目 | 内容 |
| --- | --- |
| 模型 | iTransformer（变量间注意力） |
| 参数量 | 281,752 |
| 输入特征 | `[96, 10]` 平稳化特征（E6-B 方案） |
| 输出方式 | 残差预测 `ŷ_h = z_96 + Δ_h`（残差头零初始化，从最后值基线起步） |
| 骨干超参 | `d_model=128`、`n_heads=4`、`d_ff=256`、`n_layers=2`、`dropout=0.1` |
| 优化器 | Adam，`lr=1e-3`，梯度裁剪 1.0 |
| 损失函数 | `MAE + 0.2 × MSE`，24 个预测位置等权 |
| 早停 | 按开发集 MAE，patience=3，**含 epoch 0（零残差初始化）作为候选** |
| 随机种子 | 0 |

### 输入特征（10 个变量，各为一个 token）

| # | 特征 | 说明 |
| ---: | --- | --- |
| 0 | `z_close` | 标准化收盘价（输出 token，残差锚点） |
| 1 | `z_open` | 标准化开盘价 |
| 2 | `z_high` | 标准化最高价 |
| 3 | `z_low` | 标准化最低价 |
| 4 | `amplitude` | `(High − Low) / close_std` |
| 5 | `open_close` | `(Open − Close) / close_std` |
| 6 | `log_ret` | 对数收益率（训练集 z-score） |
| 7 | `log_vol` | `log(1 + Volume)`（训练集 z-score） |
| 8 | `dividends` | 分红（训练集 z-score） |
| 9 | `splits` | 拆股（训练集 z-score） |

价格字段用每只股票的 `close_mean/close_std` 转到标签尺度；非价格特征用训练集统计量（`input_stats.json`）做 z-score。

## 3. 主要结果（vs E0 最后值基线）

| 指标 | E0 最后值 | E5 iTransformer（最佳轮次） | 差值 |
| --- | ---: | ---: | ---: |
| 开发集 MAE | 0.217307 | 0.217307（epoch 0） | 0（无改进） |
| 开发集 MSE | 0.131206 | 0.131206（epoch 0） | 0（无改进） |
| 留出集 MAE | 0.354286 | 0.354286 | 0（无改进） |
| 留出集 MSE | 0.330340 | 0.330340 | 0（无改进） |

**E5 的最佳权重就是零残差初始化本身（等价于最后值基线），训练后只会退化，没有学到任何超过最后值的可泛化信号。**

## 4. 训练轨迹（过拟合证据）

| 轮次 | 训练损失 (MAE+0.2MSE) | 开发集 MAE | 开发集 MSE |
| ---: | ---: | ---: | ---: |
| 0（初始化=最后值） | — | 0.217307 | 0.131206 |
| 1 | 0.332916 | 0.230713 | 0.152832 |
| 2 | 0.326677 | 0.252934 | 0.173051 |
| 3 | 0.322069 | 0.254875 | 0.172494 |

- 训练损失持续下降，但开发集从第 1 轮起就单调变差，早停选择 epoch 0（初始化）。
- 参照：训练集「最后值」损失约 `0.3093 + 0.2×0.2196 = 0.353`，模型第 1 轮损失 0.333 已低于它，说明模型在拟合训练期噪声而非可泛化信号。

## 5. 鲁棒性（消融，均无法超过最后值）

| 配置 | 开发 MAE / MSE | 留出 MAE / MSE |
| --- | ---: | ---: |
| 默认 (d_model=128, lr=1e-3) | 0.217307 / 0.131206（epoch 0） | 0.354286 / 0.330340 |
| lr=3e-4, wd=1e-4, dropout=0.2 | 0.236394 / 0.159828 | 0.393284 / 0.421602 |
| d_model=64, 1 层, lr=1e-4, wd=1e-4 | 0.238897 / 0.152909 | 0.376002 / 0.380739 |

降低学习率、加大正则、缩小容量均不能改变「不敌最后值」的结论。

## 6. 结论

1. **E5（iTransformer，全部行情变量）没有超过 E0 最后值基线**：最佳权重就是零残差初始化本身，开发集 MAE 0.217307、留出集 MAE 0.354286，与最后值基线完全相同。
2. **非线性变量注意力反而过拟合**：残差头零初始化使模型从最后值起步，但仅 1 个 epoch 就过拟合训练期（2020–2023，含疫情高波动段）噪声，开发集误差随之上升；降低学习率、增大正则、减小容量均无法扭转。
3. **变量注意力未优于最后值**：路线 E5↔E3 的判断应取「变量注意力未优于线性/最后值，回到简单方案」。
4. **纯行情模态可学习信号极弱**（日频股价近似随机游走），真实的预测增益预期来自新闻与财报（E7–E9）。iTransformer 的「变量即 token」设计可直接把新闻向量、财报字段作为额外 token 接入，代码可复用于后续多模态实验。
