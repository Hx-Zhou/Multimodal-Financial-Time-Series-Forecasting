# 训练与测试工作证据汇总

实验记录主要形成于 2026 年 10 月 29 日至 11 月 2 日，本次恢复、归档和校验完成于 2026 年 11 月 7 日。训练运行数依据结果 JSON 去重，代码副本、权重副本和重复来源不会增加运行数。

## 权重与预测文件

分卷保存 269 个不同内容的二进制对象，对应 357 个还原路径。归档共 467,674,423 字节，分为 23 份，每份不超过 20 MiB。原始模型、最后检查点、预测数组和历史压缩包按原字节保存。

在仓库根目录执行以下命令，先校验全部分卷及对象，再按原路径恢复文件。Python 3.10 及以上即可运行还原脚本。

```sh
python evidence/restore_artifacts.py
python evidence/restore_artifacts.py --extract --destination .
```

还原脚本会检查归档路径与 SHA-256，并保留已经存在且校验一致的文件。训练输入数据及 Python 运行库采用来源说明与接口文档，避免将环境安装文件混入工作量统计。

## 恢复范围与证据限制

- 2026 年 11 月 4 日清理时发生直接删除。本次找回了源码、训练元数据、报告、GPU 权重、预测、日志及已推送 E1 分支。51 份早期运行所引用的本机权重仍缺失，对应引用逐条列在缺失清单中。
- 本地未推送的原始 Git 对象尚未找回。相应源码通过远端副本与历史源码补丁恢复，恢复时间与实验发生时间分别记录。
- 第一批 GPU 内部留出测试的原始 `holdout_20261101` 文件目录未找回。终端中实际观测到的完整指标对象已提取，保存在 `provenance/recovered_stdout_summaries.json`，同时保留原会话、调用编号和时间。
- 部分历史工具输出在当时已被截断，个别中文终端内容存在编码损坏。导出文件保存现有观测范围，数值与结构化结果可交叉核查。
- 本次校验只核对文件哈希并重算保存预测的指标，未新增训练。第二批最终行情与多模态预测的 MAE/MSE 均与既有结果在 1e-12 容差内一致。
