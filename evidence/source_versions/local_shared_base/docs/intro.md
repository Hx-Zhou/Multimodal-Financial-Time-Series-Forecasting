# HS300 三模态股价预测项目介绍

## 1. 项目目标

本项目使用股票的日行情、新闻和财务报表三种信息，预测未来收盘价。每条样本以某只股票过去 **96 个交易日**的行情为输入窗口，结合对应时间范围内的新闻及截至输入末日的历史财报，预测随后 **24 个交易日**的标准化收盘价 `Close`。

这是一个多步时间序列回归任务。单条样本有 24 个连续数值标签；批大小为 `B` 时，模型需要输出形状为 `[B, 24]` 的有限数值，尺度与标签 `y` 一致。

## 2. 数据规模与划分

以下数量根据当前项目中的实际文件和 NPZ 数组统计。

| 项目 | 规模 | 说明 |
| --- | --- | --- |
| 训练与验证涉及的股票 | 810 只 | 两个切分均包含 810 个股票代码 |
| 训练集 | 587,587 条样本 | 每条样本是一个股票的一个输入窗口 |
| 验证集 | 76,950 条样本 | 用于调参和选择模型权重 |
| 训练与验证合计 | 664,537 条样本 | 同一股票可对应多个窗口，窗口可能重叠 |
| 行情文件 | 810 个 CSV | 每只股票一个文件 |
| 财报文件 | 2,430 个 JSONL | 810 个股票目录，每个目录三类报表 |
| 原始新闻文件 | 892 个 JSONL | 新闻库按股票代码组织，覆盖范围大于训练与验证的股票列表 |
| 新闻时间与向量编号记录 | 1,124,085 条 | 来自新闻库的 `times` 和 `vector_ids`，包含重复记录 |
| 新闻向量矩阵 | `[424257, 512]` | 424,257 行向量，每行 512 维，通过编号引用 |

新闻库的上述规模是整个文件的规模，不代表每条样本都会使用全部新闻，也不代表这些新闻都落在训练窗口中。新闻索引记录数和向量行数不相等，不能将两者都视为独立新闻篇数。

| 切分 | 样本数 | `target_start_date` 最小值 | `target_start_date` 最大值 |
| --- | --- | --- | --- |
| 训练集 | 587,587 | 2020-08-20 | 2023-08-28 |
| 验证集 | 76,950 | 2023-10-09 | 2024-02-27 |

这里的日期表示各样本的**预测区间起始日**范围，不是原始数据的完整日期范围，也不是所有标签日期的范围。行情读取器只保留 2020-03-31 至 2025-03-31 范围内的记录。当前项目提供训练集和验证集；最终测试集未公开。

## 4. 三种训练数据

### 4.1 日行情：数值时间序列

行情来自 CSV。每条样本截取连续 96 个交易日，列顺序固定为：

| 列 | 含义 |
| --- | --- |
| `Open` | 开盘价 |
| `High` | 最高价 |
| `Low` | 最低价 |
| `Close` | 收盘价 |
| `Volume` | 成交量 |
| `Dividends` | 分红记录 |
| `Stock Splits` | 拆股比例记录 |

读取器返回：

- `numerical`：NumPy `float32` 数组，形状为 `[96, 7]`。
- `dates`：NumPy `int32` 数组，形状为 `[96]`，以 `YYYYMMDD` 整数表示交易日期。

行情未经读取器标准化。模型需自行决定价格、成交量等不同量纲字段的缩放方式。

### 4.2 新闻：逐篇 512 维向量

原始新闻 JSONL 包含 `datetime`、`title`、`summary` 等字段。固定读取器直接使用 `embeddings.npz` 中预先生成的向量，不会在读取样本时重新编码新闻文字。

| 访问方式 | 类型与形状 | 内容 |
| --- | --- | --- |
| `sample["news"][d]` | NumPy `float32`，`[n_d, 512]` | 窗口第 `d` 个交易日的全部新闻向量 |
| `sample["news_time"][d]` | NumPy `int64`，`[n_d]` | 对应新闻的发布时间，整数编码为 `YYYYMMDDhhmmss` |
| `sample["news"].events()` | 二元组：`[M, 512]` 向量和 `[M]` 时间数组 | 输入首日至末日范围内的所有新闻，包括非交易日新闻 |

`n_d` 是当天新闻数量，`M` 是整个日期范围内的新闻数量，两者都不固定。无新闻的交易日返回 `[0, 512]` 空数组。因此原始新闻不能直接当作固定大小的 `[96, 512]` 数组；需要自行聚合、填充或设计其他变长输入处理方式。

`embeddings.npz` 中用于查找新闻的主要数组如下：

| 数组 | 形状 | 类型 | 用途 |
| --- | --- | --- | --- |
| `codes` | `[892]` | 字符串数组 | 新闻库中的股票代码 |
| `offsets` | `[893]` | `int64` | 每只股票在新闻索引数组中的起止边界 |
| `times` | `[1124085]` | `int64` | 新闻发布时间 |
| `vector_ids` | `[1124085]` | `int32` | 每条记录对应的向量行号 |
| `vectors` | `[424257, 512]` | `float32` | 实际新闻向量矩阵 |

查找过程是：用 `codes` 和 `offsets` 选出某股票的新闻索引，再按 `times` 筛选日期，最后通过 `vectors[vector_ids]` 取得向量。文件还保存 `members` 和 `encoder_revision`，当前读取器不使用这两个字段。

读取器保留重复新闻，去重和汇总规则由模型实现决定。

### 4.3 财报：变长结构化记录

财报包括三类：

| 类别 | 内容 | 典型字段 |
| --- | --- | --- |
| `balance_sheet` | 某个报告期末的资产、负债与股东权益 | `total_assets`、`total_liab` |
| `income` | 报告期间的收入、成本与利润 | `revenue`、`n_income` |
| `cashflow` | 报告期间经营、投资、筹资活动的现金流 | `n_cashflow_act`、`n_cashflow_inv_act` |

JSONL 解析后，一只股票的财报按 Python 类型 `dict[str, list[dict]]` 组织：外层键是报表类别，值是该类别的多期记录列表。单条记录包含股票代码 `ts_code`、报告期末 `end_date`，以及数值、字符串或空值 `None` 等字段。

`sample["financial"][kind]` 返回所有满足 `end_date <= dates[-1]` 的该类记录。它们不限于 96 天窗口内，也没有被读取器逐日填充。不同股票和类别的记录数量、字段可用性不同，因此财报原始输入没有统一的二维张量形状；模型需要自行选取字段、处理缺失值并构造固定形状或变长表示。

同一 `end_date` 可能有多条记录，读取器不去重。`financial.latest(kind)` 只按报告期末日期选一条最新记录。报告期末日不等于公告日，当前读取器没有按公告日期施加可用时间限制，训练时需明确财报的对齐规则。

## 5. 单条样本与批量形状

使用固定读取器访问样本：

```python
from hs300_dataset import HS300Dataset

train = HS300Dataset(".", "train")
sample = train[0]
```

| 字段 | 单条样本的类型与形状 | 说明 |
| --- | --- | --- |
| `stock_code` | Python `str` | 股票代码 |
| `dates` | `int32 [96]` | 输入窗口的交易日 |
| `numerical` | `float32 [96, 7]` | 原始日行情 |
| `news` | `NewsWindow` 对象 | 按需提供逐日新闻向量或整个日期范围内的新闻 |
| `news_time` | `NewsTimes` 对象 | 提供对应新闻时间 |
| `financial` | `ReportWindow` 对象 | 提供截至输入末日的历史财报 |
| `close_mean` | Python `float` 标量 | 该股票训练期收盘价均值 |
| `close_std` | Python `float` 标量 | 该股票训练期收盘价标准差 |
| `target_start_date` | Python `int` 标量 | 预测区间起始日，编码为 `YYYYMMDD` |
| `y` | `float32 [24]` | 后续 24 个交易日的标准化收盘价，仅训练和验证样本提供 |

若批大小为 `B`，行情可以堆叠为 `[B, 96, 7]`，标签堆叠为 `[B, 24]`。新闻和财报的批量形状由 `model.py` 中的 `prepare_batch(samples, device)` 决定；固定读取器不会自动把它们转换为 PyTorch 批量张量。

## 6. 标签标准化

对股票 `s` 的未来第 `h` 个交易日，标签含义为：

```text
y[s, h] = (Close[s, h] - close_mean[s]) / close_std[s]
```

`close_mean` 和 `close_std` 是按股票、仅使用训练期收盘价预先计算的固定统计量，保存在切分 NPZ 中，形状均为 `[810]`。同一股票的不同样本使用相同统计量，不会按每个 96 天窗口重新计算。项目提供读取代码，但未提供生成这些统计量的脚本。

例如 `000001.SZ` 的统计量约为 `close_mean = 13.905423`、`close_std = 3.157634`。某天收盘价为 `12.681329` 时，其标准化标签约为 `-0.387662`。

将模型预测转换回原价格尺度时使用：

```text
预测 Close[s, h] = 预测 y[s, h] * close_std[s] + close_mean[s]
```

## 7. 训练目标与评估方式

模型应综合行情、新闻和财报，学习从历史输入预测未来 24 个交易日的标准化收盘价。训练损失、模型结构和优化器可以自行选择。

验证使用标准化尺度上的 MAE 和 MSE。设验证集有 `N` 条样本，预测与标签均为 `[N, 24]`，则：

```text
MAE = sum(abs(prediction[i, h] - y[i, h])) / (N * 24)
MSE = sum((prediction[i, h] - y[i, h]) ** 2) / (N * 24)
```

求和遍历全部样本与 24 个预测位置，两项指标越低越好。验证集用于调参和选择最佳权重，最终由未公开测试集上的 MAE 和 MSE 评分。

最终提交 `model.py` 和 `model.pt`。`model.py` 需要提供无参数可调用的 `build_model()`、支持无标签样本的 `prepare_batch(samples, device)`，以及返回 `[B, 24]` 的模型 `forward(batch)`；`model.pt` 保存对应模型的 `state_dict`。当前 `model.py` 仍是待实现模板，训练循环需补充按验证表现保存最佳权重的逻辑。
